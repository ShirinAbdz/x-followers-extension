## ✨ این اکستنشن چی کار می‌کنه؟

بعد از مدتی فالو کردن، لیست Following پر می‌شه از آدم‌هایی که هیچ‌وقت فالوت نکردن.
پاک کردن دستیِ‌شون یعنی ده‌ها بار کلیک. این اکستنشن لیست Following خودت رو می‌گرده، کسایی که فالوت نکردن رو پیدا می‌کنه و آنفالو می‌کنه، **ولی فقط اگه با شرط‌هایی که خودت تعیین کردی جور باشن**.

### امکانات

- 🔎 پیدا کردن خودکار کسایی که **تو رو فالو نمی‌کنن** (از روی نشان «Follows you»، مستقل از زبان رابط X)
- ✅ **رد کردن اکانت‌های وریفای‌شده** (هم از روی تیک کنار اسم، هم از روی hover card)
- 👥 آنفالو کردن فقط اکانت‌هایی که **فالوئرشون کمتر از حد تعیین‌شده** باشه (پیش‌فرض ۱۰۰۰)
- 🛡 **لیست سفید** برای یوزرنیم‌هایی که هیچ‌وقت نباید آنفالو بشن
- 🔢 **سقف تعداد آنفالو** در هر بار اجرا (پیش‌فرض ۴۰)
- ⏱ **تأخیر تصادفی** بین هر آنفالو (پیش‌فرض ۵ تا ۱۲ ثانیه)
- 📜 **گزارش زنده** توی پنل: کی آنفالو شد، کی و به چه دلیلی رد شد
- ⏹ دکمه‌ی **توقف** هر لحظه
- 💾 **ذخیره‌ی خودکار تنظیمات**
- 🔒 **بدون سرور و بدون جمع‌آوری اطلاعات**

---

## ⚠️ قبل از استفاده بخون

- خودکارسازی فالو و آنفالو **خلاف قوانین X** هست. اگه زیاد بری ممکنه اکانتت **محدود یا موقتاً suspend** بشه. استفاده از این اکستنشن با مسئولیت خودته.
- سقف رو پایین نگه دار (مثلاً **۴۰ تا ۵۰ نفر در روز**) و تأخیر بین آنفالوها رو کم نکن.
- آنفالو کردن یه اکانت **خصوصی (Protected)** برگشت‌پذیر نیست. برای فالو دوباره‌ش باید درخواست بدی و تأییدش کنه.
- **اول با عدد کم تست کن** (مثلاً ۳ تا ۵ نفر) تا مطمئن بشی همون‌طور که می‌خوای کار می‌کنه.

## 📦 نصب

این اکستنشن توی Chrome Web Store نیست و به‌صورت دستی نصب می‌شه. کمتر از یک دقیقه طول می‌کشه:

1. این پروژه رو دانلود کن (یا زیپش رو extract کن).
2. توی کروم برو به آدرس `chrome://extensions`
3. سوییچ **Developer mode** (بالا سمت راست) رو روشن کن.
4. روی **Load unpacked** بزن و پوشه‌ی `x-cheaters` رو انتخاب کن.
5. آیکون اکستنشن رو توی نوار ابزار سنجاق کن تا همیشه دم دست باشه.

> 💡 مرورگرهای مبتنی بر Chromium مثل Edge، Brave و Opera هم باید کار کنن.

---

## 🚀 طرز استفاده

1. وارد X بشو و برو به صفحه‌ی Following خودت:
   `x.com/یوزرنیم‌تو/following`
2. روی آیکون **X Cheaters** بزن تا پنل باز بشه.
3. تنظیمات رو مشخص کن (پایین‌تر توضیح داده شده).
4. روی **شروع** بزن و تب رو باز نگه دار. اکستنشن خودش اسکرول می‌کنه و کار رو جلو می‌بره.
5. هر وقت خواستی، **توقف** رو بزن.

### تنظیمات پنل

| تنظیم                        | کاربرد                                                          | پیش‌فرض |
| ---------------------------- | --------------------------------------------------------------- | :-----: |
| **حداکثر فالوئر**            | فقط اکانت‌هایی که فالوئرشون کمتر یا مساوی این عدده آنفالو می‌شن |  ۱۰۰۰   |
| **حداکثر آنفالو در هر اجرا** | وقتی به این تعداد رسید، خودش متوقف می‌شه                        |   ۴۰    |
| **فاصله بین آنفالوها**       | بازه‌ی زمانی تصادفی (حداقل - حداکثر) به ثانیه                   | ۵ تا ۱۲ |
| **لیست سفید**                | یوزرنیم‌ها با کاما، بدون `@`. این‌ها هیچ‌وقت آنفالو نمی‌شن      |  خالی   |

### چه کسایی آنفالو **نمی‌شن**؟

| وضعیت                         | نتیجه                      |
| ----------------------------- | -------------------------- |
| تو رو فالو می‌کنه             | رد می‌شه                   |
| وریفای‌شده                    | رد می‌شه                   |
| توی لیست سفید                 | رد می‌شه                   |
| فالوئرش بیشتر از حد تعیین‌شده | رد می‌شه                   |
| تعداد فالوئرش خونده نشد       | **رد می‌شه** (برای احتیاط) |

## ⚙️ پشت صحنه چطور کار می‌کنه؟

```
 صفحه‌ی Following
      │
      ▼
 ۱. هر کاربر توی لیست بررسی می‌شه
    • نشان «Follows you» داره؟  ← رد
    • تیک وریفای داره؟          ← رد
    • توی لیست سفیده؟           ← رد
      │
      ▼
 ۲. موس روی آواتارش می‌ره تا hover card باز بشه
    و تعداد فالوئر و وضعیت وریفای از اون خونده می‌شه
      │
      ▼
 ۳. شرط‌ها جور بود؟ ← دکمه‌ی Following و بعد تأیید آنفالو کلیک می‌شه
      │
      ▼
 ۴. مکث تصادفی، بعد نفر بعدی. وقتی لیست تموم شد اسکرول می‌کنه
```

اکستنشن به **API خود X وصل نمی‌شه** و هیچ درخواست جداگانه‌ای نمی‌فرسته. فقط همون کارهایی رو می‌کنه که خودت با موس انجام می‌دی، یعنی روی دکمه‌های همون صفحه کلیک می‌کنه.

## 🛠 عیب‌یابی

<details>
<summary><b>پیام «باید توی صفحه‌ی Following باشی» می‌بینم</b></summary>

آدرس صفحه باید به `/following` ختم بشه (مثلاً `x.com/username/following`). صفحه‌ی خونه یا پروفایل کافی نیست.

</details>

<details>
<summary><b>پیام «صفحه رو رفرش کن» می‌بینم</b></summary>

اکستنشن بعد از نصب فقط توی تب‌هایی که **بعدش** باز یا رفرش شدن فعاله. صفحه‌ی X رو با `Ctrl + Shift + R` رفرش کن و دوباره امتحان کن.

</details>

<details>
<summary><b>خیلی‌ها با پیام «تعداد فالوئر خونده نشد» رد می‌شن</b></summary>

اکستنشن برای دیدن فالوئرها باید hover card رو باز کنه. اگه تب توی پس‌زمینه باشه یا کلیک و جابه‌جایی موس دخالت کنه، ممکنه باز نشه. تب رو **جلوی چشمت و فعال** نگه دار و موس رو حرکت نده.

</details>

<details>
<summary><b>کار کند شده یا وسط کار وایساد</b></summary>

مرورگر تایمرهای تب‌های پس‌زمینه رو کند می‌کنه. تب X رو در حالت فعال و قابل‌مشاهده نگه دار. اگه بعد از ۶ بار اسکرول نفر جدیدی پیدا نشه، اکستنشن خودش تموم می‌کنه.

</details>

<details>
<summary><b>X ظاهرش عوض شد و دیگه کار نمی‌کنه</b></summary>

اکستنشن به ساختار صفحه‌ی X (`data-testid`ها) وابسته‌ست و X این‌ها رو گاهی عوض می‌کنه. اگه اتفاق افتاد، باید کد آپدیت بشه.

</details>

## 🔐 حریم خصوصی

- اکستنشن **هیچ داده‌ای جمع‌آوری یا ارسال نمی‌کنه**.
- هیچ درخواست شبکه‌ای به بیرون از خود صفحه‌ی X نمی‌فرسته.
- تنظیمات فقط توی `chrome.storage.local` مرورگر خودت ذخیره می‌شه.
- هیچ سرور، آنالیتیکس یا کتابخونه‌ی خارجی‌ای توی کار نیست.
- فقط روی `x.com` و `twitter.com` فعاله.

کد با **جاوااسکریپت خالص** نوشته شده و هیچ وابستگی یا مرحله‌ی build ای نداره.

### نکات برای توسعه‌دهنده‌ها

- شناسایی عناصر با `data-testid` انجام می‌شه که به زبان رابط X وابسته نیست (مثلاً `userFollowIndicator`، `icon-verified`، `confirmationSheetConfirm`).
- تعداد فالوئر از hover card خونده می‌شه و اعداد فارسی/عربی و پسوندهای `K`، `M`، `B`، «هزار»، «میلیون» و «میلیارد» پشتیبانی می‌شن.
- پنل با `chrome.tabs.sendMessage` به content script دستور شروع و توقف می‌ده و گزارش رو با `chrome.runtime.sendMessage` پس می‌گیره.

## ⚠️ محدودیت‌ها

- X ساختار صفحه‌ش رو گاهی تغییر می‌ده و ممکنه اکستنشن نیاز به آپدیت پیدا کنه.
- فقط روی صفحه‌ی Following خودت کار می‌کنه (نه لیست دیگران).
- برای هر نفر باید hover card باز بشه، پس سرعتش محدوده و این عمدیه.
- اکانت‌هایی که فالوئرشون خونده نشه آنفالو نمی‌شن.
